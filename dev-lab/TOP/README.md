# The Odin Project — Dev Lab

This directory contains exercises and small projects developed while following **The Odin Project (TOP)** Foundations path.

## Purpose

* Practice core web development fundamentals (HTML, CSS, basic JS)
* Build hands-on understanding through incremental exercises
* Experiment freely without affecting published or portfolio-ready artifacts

## Structure

Each subdirectory represents a specific TOP lesson or project.

## CSS Exercises

CSS exercises are tracked in a separate repository:

- [TOP-css-exercises](https://github.com/JoseBossoi/TOP-css-exercises)

## Notes

This is a **development and experimentation environment**.

Stable or presentable versions of selected projects may be promoted to the  [docs](/docs) directory for publication.
