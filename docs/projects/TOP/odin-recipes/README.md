# Odin Recipes

A [simple multi-page website](https://josebossoi.github.io/career-roadmap/projects/TOP/odin-recipes/) built as part of **The Odin Project — Foundations**.

## Objective

Practice core HTML concepts by creating a small recipe website with multiple pages and internal navigation.

## Features

- Main index page linking to individual recipes
- Structured recipe pages using headings, lists, and images
- Relative paths for navigation between pages

## Learning Focus

- HTML document structure
- Semantic elements (`h1–h3`, `ul`, `ol`, `p`, `img`)
- File and folder organization
- Relative linking between pages
