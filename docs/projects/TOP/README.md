# The Odin Project — Published Projects

This directory contains selected projects developed while following **The Odin Project (TOP)** Foundations path.

## Purpose

* Present curated implementations of core web development concepts
* Demonstrate practical application of core web development fundamentals (HTML, CSS, basic JS)
* Serve as part of a structured portfolio aligned with a long-term technical roadmap

## Structure

Each subdirectory represents a specific TOP project, prepared for publication and external access.

## Notes

Only stable and presentable versions are included here.

Development, experimentation, and intermediate versions are maintained separately in the [dev-lab](../../../dev-lab/) directory.
